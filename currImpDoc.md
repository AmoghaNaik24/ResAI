## 1. Problem Diagnosis in Previous Implementation

In the prior report generation pipeline, the output document reproduced instructional paragraphs, empty placeholder blanks, and generic author prompts from uploaded DOCX templates. 

### Root Causes Identified
1. **Unfiltered Extraction:** During DOCX unzipping, `_parseDocxXmlToTemplateJSON` extracted every `<w:p>` tag directly into `sec.paragraphs` without classifying the function of the text (distinguishing headings, instructions, examples, blanks, or genuine research prose).
2. **Blind String Replacement:** In `generateReport()`, the engine simply ran string replacement for exact placeholder tokens (`{{mean_score}}`, `{{sample_size}}`). Paragraphs that contained instructional guidance (e.g., *"Write a concise abstract of approximately 150 to 250 words"*, *"The purpose of this study was to examine ________ in a sample of ________"*) contained no placeholder tokens and were copied verbatim into the final manuscript.
3. **Template Branding Preservation:** Attribution boilerplate from third-party template generators (*"Generated by GenText Group — gentext.ai"*) was retained in the document structure.
4. **Lack of Section Decision Governance:** The system had no semantic awareness of whether a section should be preserved, generated from empirical computations, adapted from research objectives, populated with metadata, omitted, or flagged for user input.

## 3. Template Decision JSON Schema & Decision Policies

The `interpretTemplate(templateJSON, profileJSON, userContext)` method evaluates each document section and content block, outputting a structured decision contract:

```json
{
  "template_id": "tpl_001",
  "document_title": "Empirical Research Report",
  "user_context": {
    "document_title": null,
    "researcher_name": "Lead Lab Investigator",
    "research_objective": null,
    "literature_sources": null
  },
  "sections": [
    {
      "section_id": "sec_results",
      "original_heading": "4. Results",
      "required": true,
      "section_type": "analytical_results",
      "decision": "generate",
      "reason": "The section requires empirical statistical findings computed directly from the uploaded dataset.",
      "evidence_sources": ["verified_results_json", "dataset_profile"],
      "required_inputs": [],
      "planned_outputs": [
        "descriptive_statistics",
        "relevant_tables",
        "supported_visualizations",
        "inferential_test_statistics"
      ],
      "unresolved_items": [],
      "status": "ready"
    }
  ],
  "global_requirements": {
    "citation_style": "APA 7",
    "preserve_template_formatting": true,
    "strip_template_instructions": true,
    "strip_blank_underscores": true,
    "strip_template_branding": true
  },
  "blocking_questions": [],
  "warnings": []
}
```

### Supported Decisions and Rules
- `keep`: Preserves valid template content when genuine, user-authored research prose is detected in an uploaded template.
- `populate`: Fills metadata fields (Title page, Investigator, Date, Session ID) from verified user context or file metadata without fabricating missing institutions or courses.
- `generate`: Synthesizes objective narrative and tables strictly from canonical results (Results, Methodology, Limitations, Table 1).
- `adapt`: Rewrites section purpose for the actual study (Abstract, Introduction, Discussion, Conclusion) based on empirical variables, research objectives, sample size, and verified statistics.
- `omit`: Removes author instructions, formatting advice (e.g. margin/font guidelines), and template-generator branding (`gentext.ai`).
- `ask_user`: Flags required external context that cannot be derived from data alone (e.g. literature sources). Prohibits fabricating fictitious papers, authors, or DOIs.

## 4. Content Block Filtering and Text Classification

### Function: `isInstructionOrExampleParagraph(text)`
Identifies and filters out non-empirical boilerplate:
1. **Placeholder Blanks:** Detects 3 or more underscores (`/_{3,}/`) and empty bracket fields (`/\[(insert|your|university|course|date|instructor|author)[^\]]*\]/i`).
2. **Template Generator Branding:** Detects third-party generator attributions (`/gentext\s*(group|\.ai)|generated\s+by\s+gentext/i`).
3. **Instructional Imperatives:** Filters writing prompts:
   - "Write a concise abstract of approximately 150 to 250 words."
   - "Begin the introduction by establishing the research problem."
   - "Summarize the most relevant scholarly sources."
   - "Replace every blank line with your own information."
   - "Use a professional academic layout."
   - "The purpose of this study was to examine ________ in a sample of ________."
4. **Preservation Safeguard:** Does not strip genuine research prose (e.g. *"Prior empirical literature (Smith & Jones, 2021) established baseline methodologies..."*), ensuring real citations and author sentences remain intact.

## 5. Direct Word OpenXML Editing Engine

### Method: `_replaceWordXml(xmlString, resMap, decisionsJSON, sectionReplacementMap)`
Directly manipulates WordprocessingML (`word/document.xml`) inside the DOCX ZIP container:
1. **Section Heading Preservation:** Retains `<w:pStyle w:val="Heading1"/>` and original styling for required sections; completely removes paragraph nodes for omitted sections (`Formatting Guidelines`).
2. **Branding Stripping:** Identifies and strips generator attribution paragraphs from XML.
3. **Split Run Consolidation:** Matches placeholders across split `<w:r>` tags and multi-placeholder paragraphs, writing consolidated replacement text into the primary `<w:t xml:space="preserve">` node and clearing redundant split fragments.
4. **Table Cell Integrity:** Replaces metric placeholders inside table cells (`<w:tbl><w:tr><w:tc><w:p>`) without altering table borders, shading, or alignment XML.
5. **Instruction Replacement:** In adapted sections (Abstract, Introduction), replaces instructional text runs with empirical synthesized text grounded in verified data calculations.

## 6. Decision-Aware Validation Engine

### Method: `validateReport()`
Validation produces an auditable verification JSON checking beyond file generation:
1. **Template Integrity Checks:**
   - `chk_instruction_removal`: Confirms zero instructional template sentences remain.
   - `chk_placeholder_removal`: Confirms zero blank underscores (`___`) or unfilled brackets remain.
   - `chk_branding_removal`: Confirms zero third-party generator branding remains.
2. **Canonical Numerical Match:**
   - Every reported numerical claim in the narrative is checked against `verifiedResultsJSON`.
   - Sample standard deviation uses Bessel's correction ($N - 1$).
   - Student's t and Welch's t statistics verify Lanczos $\ln\Gamma(z)$ and incomplete beta evaluation.
3. **Ungrounded Test Guard:**
   - If a categorical grouping variable is absent, hypothesis testing ($t$, $p$, $d$) is formally marked `blocked`. P-values are never manufactured. Validation status switches to `blocked` if ungrounded tests are claimed.
4. **Citation Protection:**
   - Academic publication years (1950–2050) and parenthetical citations are protected from false ungrounded numerical penalties.
